# S M Siddalingaswamy — Portfolio Website

A professional personal portfolio website built to showcase my profile, technical skills, and featured projects in Full-Stack Development and AI.

## Overview

This portfolio is designed with a modern dark theme, responsive layout, and clean user experience. It highlights:

- Professional introduction and profile summary
- Skills across frontend, backend, cloud, and AI tools
- Project showcase with repository/demo links
- Contact section and social links

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome

## Project Structure

```text
naviPortfolio/
├── index.html          # Main page structure and content
├── styles.css          # Styling, layout, and animations
├── script.js           # Interactions and dynamic behavior
├── assets/             # Images used across the portfolio
└── README.md           # Project documentation
```

## Getting Started

### 1) Clone the repository

```bash
git clone https://github.com/navi-siddu-1103/naviPortfolio.git
cd naviPortfolio
```

### 2) Run locally

You can open `index.html` directly in a browser, or serve it locally:

```bash
python -m http.server 8000
```

Then visit: `http://localhost:8000`

## Customization

### Update personal information
Edit `index.html` to update:

- Name, title, and bio
- Skills and project details
- Social links (GitHub, LinkedIn, portfolio URL)
- Contact details

### Update media assets
Replace files inside `/assets` with your own profile and project images.

### Update theme styling
Edit CSS variables and section styles in `styles.css` to match your brand.
